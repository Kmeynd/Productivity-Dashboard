# 📊 Productivity Dashboard

A personal web app to track and visualize my productivity over time.  
This dashboard helps you stay accountable by showing what you've completed recently, with multiple perspectives on my progress: stats, charts, and a heatmap.

## 🚀 Features

- ✅ **Task Completion Tracking** — Log and view my completed tasks.
- 📈 **Stats Section** — See summaries like total tasks completed, daily/weekly averages, and streaks.
- 📊 **Graph Section** — Visualize my productivity with dynamic charts using Chart.js.
- 🔥 **Heatmap View** — Spot trends and consistency in my workflow over time.

## 🛠️ Tech Stack

- **Backend:** Node.js with Express
- **Frontend:** EJS templating + Chart.js for visualizations
- **Database:** PostgreSQL
- **Validation:** express-validator
- **Environment Config:** dotenv
